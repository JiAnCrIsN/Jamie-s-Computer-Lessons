3RD QUARTER

JavaScript

JavaScript is a fundamental web technology that plays a crucial role in making websites interactive, dynamic, and functional. It works together with HTML (which provides the structure) and CSS (which is responsible for design), forming the three core pillars of web development.

1. Core Logic & Data Handling

Through the use of variables, operators, statements, and data types, JavaScript is able to store, process, and manipulate data efficiently.

2. Control Flow & Interactivity

Control flow structures, such as conditional statements and loops, allow programs to make decisions, repeat actions, and respond seamlessly to user inputs like clicks, typing, and hovering.

3. Separation of Concerns

The concept of separation of concerns emphasizes the importance of organizing code into separate files for HTML, CSS, and JavaScript. This best practice drastically improves code readability, maintainability, and scalability as websites grow more complex.

4. Execution & Implementation

By utilizing internal or external scripts, along with proper coding structures, developers can build responsive, user-friendly, and highly engaging web pages that perform everything from simple content updates to advanced interactive applications.

4TH QUARTER

JavaScript Functions

JavaScript functions are essential for organizing code into reusable and manageable parts. They allow developers to group related instructions into a single block that can be executed multiple times throughout a program, drastically improving structure and efficiency.

1. Code Reusability & Simplification

By declaring and calling functions, programmers can simplify complex tasks, completely avoid repetitive blocks of code, and make their projects significantly easier to test and maintain over time.

2. Parameters & Arguments

Functions become highly flexible through the use of parameters and arguments. This capability allows a single function to accept different data inputs dynamically and compute unique, flexible results based on what was passed into it.

3. The Return Statement

The return statement enables functions to send computed values directly back to the exact place where they were originally called. This makes them incredibly powerful for executing calculations and logic operations.

4. Modular Programming

Overall, functions are the building blocks of clean, modular programming. They help developers break down large, overwhelming problems into smaller, logical, and digestible pieces that are much easier to manage.
